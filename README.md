\# 🛡️ Network Intrusion Detection System (NIDS)



Deep Learning based Anomaly Detection using Autoencoder Neural Network



\## 🌐 Live Demo

\*\*\[Click Here to View Live Website](https://kumarsusheel7497-collab.github.io/nids-frontend/)\*\*



\## ✨ Features



\- 🎯 Real-time Network Traffic Monitoring

\- 🧠 Deep Learning Autoencoder Model

\- 📊 Interactive Dashboard with Charts

\- 🚨 Detects 4 Attack Types:

&#x20; - DoS (Denial of Service)

&#x20; - Probe (Network Scanning)

&#x20; - R2L (Remote to Local)

&#x20; - U2R (User to Root)

\- 📈 Real-time Analytics

\- 📜 Detection History

\- 🎓 Model Training Interface



\## 🛠️ Technology Stack



\### Frontend

\- HTML5, CSS3, JavaScript

\- Chart.js for Visualizations

\- Font Awesome Icons



\### Backend

\- Python 3.11

\- Flask REST API

\- TensorFlow / Keras

\- Scikit-learn



\### Machine Learning Model

\- Architecture: Deep Autoencoder

\- Layers: 41 → 32 → 24 → 16 → 24 → 32 → 41

\- Accuracy: 95% Normal, 100% Attack Detection
